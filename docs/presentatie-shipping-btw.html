Stap 1: Checkout

De klant komt op de checkout pagina en vult zijn factuuradres in. Het systeem kijkt automatisch naar het gekozen land.

Stap 2: Land Detectie

Zodra een EU-land buiten Nederland wordt geselecteerd, verschijnt er een extra optie:

Ik bestel zakelijk (BTW verlegd)

Stap 3: Zakelijke Bestelling

Als de klant "Ik bestel zakelijk" aanvinkt, verschijnt een veld voor het BTW-nummer:

Ik bestel zakelijk (BTW verlegd)
✓ BTW-nummer gevalideerd

Stap 4: VIES Validatie

Het BTW-nummer wordt automatisch gecontroleerd via de officiële EU VIES database.

  • Geldig nummer: Groen vinkje, BTW wordt verwijderd
  • Ongeldig nummer: Foutmelding, normale BTW blijft
  • API niet bereikbaar: Order gaat door, handmatige controle later

Stap 5: Resultaat

Bij een geldig BTW-nummer:

  • Alle prijzen worden exclusief BTW getoond
  • De factuur vermeldt "BTW verlegd"
  • Het BTW-nummer van de klant staat op de factuur
  • Verzendkosten zijn ook zonder BTW
